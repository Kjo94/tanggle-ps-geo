# damara.my

성형·의료 시술 안내 사이트. 시술마다 **비용이 달라지는 기준**, **회복 경과**,
**병원을 고를 때 확인할 점**을 정리했습니다.

- 한국어: <https://damara.my/>
- English: <https://damara.my/en/>

## 게재 원칙

- 병원이 직접 확인한 값만 게재하며, 확인되지 않은 금액·기간은 추정해서 채우지 않습니다.
- 각 페이지에 마지막 확인일과 참고 자료(대한성형외과학회·건강보험심사평가원 등)를 표시합니다.
- 병원 간 순위나 우열을 평가하지 않습니다.
- 본 사이트의 내용은 일반적인 정보 안내이며 의료진의 진단·상담을 대체하지 않습니다.

## 구조

```
damara.my/                 안내 메인 (한국어)
├── en/                    English
└── <병원>/                 병원별 시술 안내
    └── en/                English
```

이 저장소는 위 사이트의 정적 파일입니다.
